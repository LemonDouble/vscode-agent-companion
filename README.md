# Agent Companion

Claude Code와 Codex CLI로 여러 프로젝트를 동시에 작업할 때 사용하는 VS Code 확장입니다.

프로젝트들을 담은 상위 폴더를 열고 터미널마다 다른 프로젝트로 이동해 사용하는 구성을 지원합니다. 멀티 루트 워크스페이스에서도 동작합니다.

## 주요 기능

- 터미널을 선택하거나 `cd`로 이동하면 탐색기가 해당 폴더를 펼칩니다.
- 에이전트의 응답 완료와 입력 대기를 알림과 알림음으로 알려 줍니다. **터미널로 이동**을 누르면 해당 세션으로 이동합니다.
- 상태바에 작업 중, 입력 대기, 응답 완료 세션 수를 표시합니다. 클릭하면 세션을 선택해 터미널로 이동할 수 있습니다.
- 탐색기에서 파일·폴더를 우클릭하고 **Add Path to AI Chat**을 선택하면 활성 터미널에 절대 경로를 입력합니다.

## 설치

1. [Releases](https://github.com/LemonDouble/vscode-agent-companion/releases)에서 `.vsix` 파일을 받습니다.
2. VS Code 확장 뷰 > 우측 상단 `...` > **Install from VSIX...** 메뉴로 설치합니다.

WSL에서는 WSL에 연결된 VS Code 창에서 설치합니다.

## 설정

### 훅 설치

알림과 상태 표시에는 에이전트 훅이 필요합니다.

1. 커맨드 팔레트에서 **Agent Companion: Claude Code/Codex 훅 설치/업데이트**를 실행합니다.
2. Codex는 `/hooks`에서 설치한 훅을 승인합니다. 업데이트 후에도 다시 승인해야 합니다.
3. 에이전트 세션을 새로 시작합니다.

- `~/.claude/settings.json`, `~/.codex/hooks.json`에 훅을 추가합니다. 설정 폴더가 없는 에이전트는 건너뜁니다.
- 변경 전 기존 파일을 `.bak`으로 백업하고, 이 확장과 관련 없는 훅은 유지합니다.

### 기능 설정

- VS Code 설정에서 `agentCompanion`을 검색하면 기능별로 켜거나 끌 수 있습니다.
- 터미널 탭에 현재 폴더명을 표시하려면 `"terminal.integrated.tabs.title": "${cwdFolder}"`로 설정합니다.

## 작동 원리

- 터미널 셸 통합으로 현재 폴더를 확인해 탐색기를 동기화합니다.
- 에이전트 훅이 남긴 이벤트 파일로 알림과 세션 상태를 갱신합니다.

## 요구사항

- VS Code 1.93 이상과 터미널 셸 통합이 필요합니다.
- 세션 구분과 종료 감지, 터미널 연결에 `/proc`을 사용하므로 Linux 또는 WSL이 필요합니다.
- Claude Code 또는 Codex CLI가 필요합니다.
